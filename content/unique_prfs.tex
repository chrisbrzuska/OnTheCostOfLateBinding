The hash-based key derivation function (HKDF) used by TLS 1.3 is an essential building block for achieving the binding property of the protocol. Indeed, it is not sufficient to model the HKDF as a pseudorandom function (PRF), as a PRF is not necessarily collision-resistant for a fixed key. Therefore, we model the HKDF as a Unique PRF, which both has a pseudorandomness property as well as a collision resistance property.

The Unique PRF package is connected to two keys, the input and the output key (see Figure~\ref{fig:PRF_graph}). Further, it provides access to the evaluation function. On a evaluation call for a handle, the Unique PRF accesses the corresponding key from the input\_key package, uses this key to calculate the PRF value of the handle (i.e., it \emph{binds} the key to the handle) and saves the returned value as key in the output\_key package (see Figure~\ref{fig:PRF_pkg}). Further, it translates the honesty bit from the input key to the output key, i.e., if the input key for a specific handle is marked as honest, then the resulting output key is also marked as honest.

A Unique PRF is secure if it is indistinguishable from the PRF in an ideal environment. For this, we define two games PRF\_real and PRF\_ideal: In both games, we assume that the input keys are random for all honest keys. For the ideal world, we further define the output keys as unique, i.e., there are no collisions. Further, for all honest keys, the output keys are replaced with random keys. With these games, we say that a Unique PRF is secure if the distinguishing advantage between these two games is negligible.

\begin{definition}[Unique PRF]
\label{advantage:theorem:Main:PRF_real:PRF_ideal}
Let $Unique\_PRF\_real:=Unique\_PRF^0$ and $Unique\_PRF\_ideal:=Unique\_PRF^1$.
A Unique PRF is secure if for all PPT adversaries $\adv$, the advantage $\mathsf{Adv}(\adv;Unique\_PRF\_real,Unique\_PRF\_ideal):=$
\[\abs{\begin{array}{l}\phantom{-}\prob{1 = \adv\rightarrow Unique\_PRF\_real}\\-\prob{1 = \adv\rightarrow Unique\_PRF\_ideal }\end{array}}.
\]
is negligible in the security parameter.
\end{definition}

\subsection{Assumptions}

We show the security of the Unique PRF based on two assumptions: A standard PRF assumption of pseudorandomness of the output, as well as a collision resistance on the outputs. We will start with the PRF assumption. The PRF package has two interfaces: NEW\_KEY generates a key for a given handle if no key exists for this handle yet (see Figure~\ref{fig:PRF_mon_pkg}). EVAL, in the real world, evaluates the PRF on the handle and its corresponding key. In the ideal world, however, EVAL randomly samples outputs for the respective handle.

 \label{fig:PRF_mon_pkg}

By standard PRF security, the real and ideal world should be indistinguishable:

\begin{definition}[PRF]
\label{advantage:assumption:PRF:PRF_mon_real:PRF_mon_ideal}
For all adversaries $\adv$, we define the PRF advantage as\[\mathsf{Adv}(\adv;PRF_real,PRF\_ideal):=\abs{\begin{array}{l}\phantom{-}\prob{1 = \adv\rightarrow PRF\_real}\\-\prob{1 = \adv\rightarrow PRF\_ideal}\end{array}}.
\]
A PRF is secure if, for every adversary, the above advantage is negligible.
\end{definition}

\begin{figure}
 \centering
 \input{content/domino_imports/Package_hash_in_Game_CR}
 \caption{The collision resistance game}
 \label{fig:CR_hash}
\end{figure}

The second assumption on the PRF is collision resistance. For this, we define a package hash with an interface HASH, which, for a fixed function f (in our case, the PRF), and inputs $(x,y)$, computes the $f(x,y)$, saves the result in a table, and returns the result. In the ideal world, we further check if any collisions have happened between the current and previous calls, and abort if this should be the case (see Figure~\ref{fig:CR_hash}). Now, standard collision resistance gives us that these two worlds should be indistinguishable:

\begin{definition}[CR]
\label{advantage:assumption:CR:CR_real:CR_ideal}
For all adversaries $\adv$, we define the CR advantage as\[\mathsf{Adv}(\adv;CR\_real,CR\_ideal):=\abs{\begin{array}{l}\phantom{-}\prob{1 = \adv\rightarrow CR\_real}\\-\prob{1 = \adv\rightarrow CR\_ideal}\end{array}}.
\]
We say that the function $f$ is collision-resistant if the above advantage is negigible.
\end{definition}

This allows us now to state our main theorem for this section:

\begin{theorem}[Main]
We prove that for all adversaries $\adv$, there are reductions $\rdv_{1}$, $\rdv_{2}$ such that \begin{align*}\mathsf{Adv}(\adv, PRF\_real, PRF\_ideal)) \leq &\mathsf{Adv}(\adv\rightarrow\rdv_{1},\mathit{CR\_ideal},\mathit{CR\_real}) \\+ &\mathsf{Adv}(\adv\rightarrow\rdv_{2},\mathit{PRF\_mon\_ideal},\mathit{PRF\_mon\_real}).\end{align*} %where reduction $\rdv_1$ is defined in Fig.~\ref{figure:reduction:CR:CR_Reduction_real:CR_Reduction_ideal}, reduction $\rdv_2$ is defined in Fig.~\ref{figure:reduction:PRF:PRF_Reduction_real:PRF_Reduction_ideal}
\end{theorem}
